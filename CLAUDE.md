# CLAUDE.md

## HTML Best Practices
- Follow the Playwright-friendly HTML guidelines in `docs/playwright-friendly-html.md` when writing or modifying HTML. Key points: use `data-testid` attributes, semantic HTML/ARIA, `name` attributes on form inputs, and avoid selectors tied to styling.

## Writing
Write documentation, error messages, log messages and code comments in plain English, following the rules in
README.md, "Writing documentation".
